## Purpose
Execute a complete IT request process in decentralized higher education environments from initial intake through evaluation, capability matching, governance routing, and stakeholder communication. Use this to ensure consistent handling of all IT requests, maximize use of existing capabilities, route decisions appropriately, and maintain transparency with requestors.

This is not a project management methodology—it's an intake and routing workflow that determines whether, how, and when to proceed with IT requests before committing to implementation.

## Key Concepts

### The Complete Request Journey
A typical IT request in higher ed goes through these stages:

**Stage 1: Intake & Triage** (Days 1-3)
- Request arrives via formal template or informal conversation
- Initial completeness check and acknowledgment
- Categorize by type, scope, and urgency

**Stage 2: Capability Discovery** (Days 4-10)
- Check existing campus capabilities first
- Match functional needs to existing solutions
- Identify if perfect match, close match with gaps, or genuine new need

**Stage 3: Governance Routing** (Days 11-15)
- Determine appropriate review path (fast-track, standard, strategic)
- Identify stakeholders and decision-makers
- Set expectations for timeline

**Stage 4: Evaluation & Decision** (Weeks 3-8)
- Detailed evaluation (if new capability needed)
- Stakeholder input and consensus-building
- Governance decision: Approve, defer, or decline

**Stage 5: Communication & Next Steps** (Week 8+)
- Communicate decision with rationale
- Implementation planning OR backlog placement

### Three Routing Paths

**Fast Track** (1-2 weeks) - Existing capability match OR unit-specific, low resource
**Standard Review** (1-2 months) - New capability OR multi-unit OR medium resource  
**Strategic Review** (3-12 months) - Campus-wide OR strategic OR high resource

### When to Use This Workflow
- New IT request arrives from any campus unit
- Informal conversation becomes formal request
- Strategic planning identifies potential new capability
