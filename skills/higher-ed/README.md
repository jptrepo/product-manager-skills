# Higher Education Project Management Skills

**Adapted PM frameworks for higher education IT governance, transparency, and communication.**

## Context: The Decentralized Challenge

Higher education institutions face unique project management challenges:

- **Decentralized decision-making:** Academic units, administrative departments, and IT operate semi-independently
- **Siloed knowledge:** Units request software without knowing what capabilities already exist on campus
- **Competing priorities:** Limited IT resources face demands from multiple stakeholders with different goals
- **Governance gaps:** Lack of transparent processes for evaluating, prioritizing, and communicating IT decisions
- **Communication barriers:** Academic culture, administrative needs, and technical requirements don't always align

**This collection provides agent-ready frameworks to facilitate governance, transparency, and communication across decentralized IT environments.**

## 📖 Philosophy for Higher Ed IT

**Principles:**
- **Transparency over gatekeeping** — Make IT priorities and capacity visible to all units
- **Governance over ad-hoc** — Establish clear processes for evaluating and prioritizing requests
- **Collaboration over silos** — Connect requestors with existing capabilities before creating new ones
- **Communication over assumption** — Bridge academic, administrative, and technical languages
- **Evidence over politics** — Base decisions on data, impact, and strategic alignment
